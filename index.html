☀️ Supercomputing (Mon + Thu mornings)
Wk 1
CPUs vs GPUs — what and why
Computerphile 'How GPUs Work'. Why AI needs massive parallel compute. FLOPS, memory bandwidth concepts.
Wk 1
HPC architecture overview
TOP500 list context. Interconnects, NUMA, distributed memory. MIT 6.172 Lecture 1.
Wk 2
CUDA programming concepts
What a kernel is. Thread blocks. GPU memory hierarchy. First CUDA mental model.
Wk 2
Parallel Python — multiprocessing
Python multiprocessing module. Joblib. How HPC jobs are structured.
Wk 3
MPI basics + LLNL tutorials
Message Passing Interface — how supercomputer nodes talk. Lawrence Livermore free tutorials.
hpc.llnl.gov/tutorials
Wk 3+
NumPy/CuPy — GPU arrays in Python
CuPy is NumPy but on GPU. Write your first GPU-accelerated Python code.
☀️ Quantum Computing (Tue + Fri mornings)
Wk 1
Qubits, superposition, entanglement
IBM 'What is Quantum Computing?' (5 min). Microsoft Research intro (first 15 min). Pure concepts, no math.
Wk 1
Quantum gates and circuits
How quantum gates work like classical logic gates but with amplitudes. Bloch sphere intuition.
Wk 2
Qiskit — first quantum circuit
Install Qiskit. Build a Bell state (quantum entanglement in code). Run on IBM simulator.
learning.quantum.ibm.com
Wk 2
Run on real quantum hardware
IBM gives free access to real quantum computers. Submit your circuit. See quantum noise in real results.
Wk 3
Grover's search + Shor's algorithm
Why quantum beats classical for specific problems. Conceptual understanding, not full proofs.
Wk 3+
Quantum ML — PennyLane
QML intro at pennylane.ai. The AI+quantum intersection. Very relevant to fellowship context.
pennylane.ai/qml
☀️ Robotics (Wed + Sat mornings)
Wk 1
What is ROS? Nodes and topics
'ROS for Beginners' intro video (15 min). Node/topic/publisher/subscriber mental model. Why ROS exists.
Wk 1
Sensors, actuators, control loops
How robots perceive and act. IMUs, LiDAR, cameras. Basic PID control concept.
Wk 2
ROS 2 install + first node
Install ROS 2 (or Docker). Complete beginner CLI tutorials. Run your first publisher/subscriber pair.
docs.ros.org/tutorials
Wk 2
Kinematics basics
Forward and inverse kinematics. How robot arms calculate position. MIT 6.832 Lecture 1.
Wk 3
RL for robotics + OpenAI Gym
Gymnasium simulation. CartPole environment. How RL agents learn to control robots.
gymnasium.farama.org
Wk 3+
Embodied AI — LLMs + Robots
How LLMs are being used to control robots. RT-2, SayCan, PaLM-E papers. Hottest intersection in AI.
